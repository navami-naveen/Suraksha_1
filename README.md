The Problem statement

Today,personal safety, especially for women and elderly people, is a growing concern. Women often face the risk of harassment, and elderly individuals may encounter emergencies or disorientation without immediate assistance.Hence there is a need for a reliable system that can alert guardians instantly and provide live location tracking during emergencies.

The Solution

Suraksha is a safety application designed for women and elderly users. It provides real-time emergency alerts and location sharing with trusted guardians through a disguised chat interface or geofencing alerts.

Technical Details
For Software:

Languages used: HTML, CSS, JavaScript
Frameworks used: node.js
Tools used: VS Code

Feature 1: Role-Based Login: Users select either Women or Elderly mode for personalized safety options.

Feature 2: Guardian Management: Add multiple trusted contacts to receive emergency alerts.

Feature 3: Disguised Chat Interface: Women’s emergency triggers hidden in a normal-looking chat system.

Feature 4: Fake Call Trigger: Typing “911” in chat initiates a fake incoming call.

Feature 5: Location Sharing: If the fake call is declined or the elderly user leaves a safe zone, live location is automatically sent to guardians.

Feature 6: Safe Zone Geofencing: Alerts sent when elderly users step outside the designated area.
